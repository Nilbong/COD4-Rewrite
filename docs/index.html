Call of Duty 4 multiplayer, rebuilt.

A from-scratch reimplementation on the Bevy engine. It reads maps, models and textures from your own game installs at runtime, the way OpenMW does for Morrowind. The repository ships no game data.

Features

The real game, on a modern engine

It uses CoD4's own fastfiles, menus and rules, so it plays like the game you remember.

Loads the real files

Decompresses .ff zones and parses the IW3 asset stream: materials, images, models, world geometry, collision and map entities. Every multiplayer map's zone parses.

The original menus

An interpreter for the IW3 menu system runs CoD4's own menus: main menu, Private Match and Create a Class, with fonts, sounds and music.

Progression

CoD4's XP, the 55 ranks and per-weapon challenges, with attachments and camos as unlocks. Stats are saved locally.

Create a Class

Stack a sight, silencer and grip on one gun. Weapons are rotatable 3D previews showing the attachment and camo you picked.

Bots that play like you

Record your matches, fit a profile with a Python tool, and bots adopt your reaction time, aim speed, strafing and fighting range.

Splitscreen co-op

Two to four local players, each with their own camera, HUD and controller: DualSense, DualShock 4, Xbox, Switch Pro, or keyboard and mouse.

Controller support

Gamepads map onto the keyboard bindings, with aim assist, on-screen glyphs for your controller, and rumble.

Built-in bug reports

F10 screenshots, pauses and saves a report with the map, positions and every bot's state. A free-camera spectator mode follows bots by name or role.

Requirements

Bring your own games

No game data is distributed here. CoD4 is required. Black Ops and World at War are optional installs that add their weapons and characters to the game.

1
Required

Call of Duty 4: Modern Warfare

Steam or retail, patch 1.7. Provides the maps, menus, models, textures and sounds.

COD4_PATH → folder with iw3mp.exe
2
Optional

Call of Duty: Black Ops

Adds Black Ops' weapons, attachments, animations, sounds and characters.

  • Weapons picked from a "Black Ops" list in Create a Class
  • Black Ops soldiers
BLACKOPS_PATH → folder with BlackOps.exe
3
Optional

Call of Duty: World at War

Adds World at War's multiplayer guns, equipment and characters, converted at load time.

  • Guns such as the Kar98k, M1 Garand and PTRS-41
  • World at War soldiers
WAW_PATH → folder with CoDWaWmp.exe

Installs in common Steam library locations are found automatically. Set the variable only if yours isn't. You also need a Rust toolchain.

Game modes

Pick a fight

All three are playable against bots on the multiplayer maps.

Free-for-all

Everyone against everyone. First to the score limit wins.

Domination

Hold flags to earn points. Bots learned their flag play from recorded human demos.

Search & Destroy

Plant or defuse the bomb. One life per round.

Run it

Up and running

Needs the Rust toolchain and the games from the requirements above.

  1. Install your games. CoD4 is required. Add Black Ops and World at War for their weapons and characters.
  2. Clone and run. Game folders are found automatically in common Steam locations.
git clone https://github.com/Nilbong/COD4-Rewrite.git
cd COD4-Rewrite
cargo run --release -p game

Skip the menus and drop straight into a match:

cargo run --release -p game -- --map mp_killhouse --bots 6
