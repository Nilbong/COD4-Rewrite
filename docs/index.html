Call of Duty 4 multiplayer,
rebuilt in Rust.

A from-scratch reimplementation on the Bevy engine. It reads maps, models and textures from your own CoD4 install at runtime, the way OpenMW does for Morrowind. The repository ships no game data.

Get started View on GitHub

What it does

The game's own fastfiles, menus and rules, running on a modern engine.

Loads the real game files

Decompresses .ff zones and parses the IW3 asset stream: materials, images, models, world geometry, collision and map entities. Every multiplayer map's zone parses.

The original menus

An interpreter for the IW3 menu system runs CoD4's own menus from ui_mp.ff: main menu, Private Match and Create a Class, with fonts, sounds and music.

Create a Class and progression

CoD4's XP, the 55 ranks, per-weapon challenges, attachments and camos, saved locally. Classes can stack a sight, silencer and grip, and weapons are rotatable 3D previews.

Bots that play like you

Record your own matches, fit a profile with a Python tool, and bots adopt your reaction time, aim speed, strafing and fighting range.

Splitscreen co-op

Two to four local players, each with their own camera, HUD and controller, including DualSense, DualShock 4, Xbox and Switch Pro.

Weapons from three games

CoD4 guns plus Black Ops and World at War weapons converted at load time from your installs of those games.

Controller support

Gamepads map onto the keyboard bindings, with aim assist, controller glyphs and rumble.

Built-in debugging aids

F10 takes a screenshot, pauses, and saves a bug report with the map, positions and every bot's state. A free-camera spectator mode follows bots by name or role.

Game modes

Playable with bots on the multiplayer maps.

Free-for-all

Everyone against everyone.

Domination

Hold flags to earn points, with bot flag play learned from recorded demos.

Search & Destroy

Plant or defuse the bomb, one life per round.

Run it

You need a Rust toolchain and an installed copy of CoD4 (Steam or retail, patch 1.7).

  1. Clone the repository.
  2. Run the game. The install is found automatically in common Steam library locations. If it isn't, set COD4_PATH to the folder containing iw3mp.exe.
git clone https://github.com/Nilbong/COD4-Rewrite.git
cd COD4-Rewrite
cargo run --release -p game

Skip the menus and drop straight into a match:

cargo run --release -p game -- --map mp_killhouse --bots 6
