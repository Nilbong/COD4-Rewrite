What it is

A modern take on a classic

This is a COD4 rewrite using Rust and Bevy. The goal is to modernize and improve on the original game while retaining its core feel and mechanics.

It also supports Black Ops, World at War and Modern Warfare 2 weapons, characters and maps, with more games to be added in the future such as MW3 and BO2. It also supports custom maps made for the original CoD4 and the other games mentioned.

The repository contains no game data. Everything is read from your own installs at runtime.

Download and play

Download, open, play

No Rust or other tools needed. The launcher fetches the latest build of the game for you and keeps it up to date.

  1. Own Call of Duty 4: Modern Warfare. It is required, because the game reads its maps, models and sounds from your install. Black Ops, World at War and Modern Warfare 2 are optional and add their content if you have them installed.
  2. Download the ZIP and unzip it anywhere.
    Download ZIP
  3. Open Launcher.exe. It downloads the latest release of the game from GitHub into a game folder beside it, then starts the game. Each time you open it, it checks for a newer release and updates first.

You need Windows and a graphics card with Vulkan. No game files are downloaded or included, because everything is read from your own installs, found automatically in common Steam locations.

Build from source (optional)

Only needed if you want to modify the game. Install a Rust toolchain, then:

git clone https://github.com/Nilbong/COD4-Rewrite.git
cd COD4-Rewrite
cargo run --release -p game

Skip the menus and go straight into a match:

cargo run --release -p game -- --map mp_killhouse --bots 6

The full option list, controls and format notes are in the README.

Bug reports

Found a bug? Press F10

The game has a built-in bug reporter. A report is one screenshot plus a text file with what was going on, which makes bugs much easier to track down.

  1. Press F10 in game. It takes a screenshot, pauses the game and asks what's wrong.
  2. Type a description and press Enter to save the report (Esc throws it away).
  3. Find the two files in the bugreports folder: a .png screenshot and a .txt with your description, the map, the time, where you and the camera are, and what every bot was doing.
    • Started with Launcher.exe: game\bugreports, inside the folder you unzipped.
    • Built from source: bugreports in the folder you ran the game from.
  4. Send both files to the Discord channel.
    Open the Discord channel

The .txt file includes the file path of the game, which can contain your Windows username. Open it before sharing and remove that line if you'd rather not post it.
